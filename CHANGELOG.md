# Changelog

## 1.4.0 (не опубликована)

- `jest.reportPath` принимает строку или непустой массив путей к JSON-отчетам Jest/Vitest. Старые конфигурации менять не требуется.
- `validate` и `sync` обрабатывают тесты из всех отчетов, сохраняя проверку дубликатов.
- `upload-stat` отправляет общую статистику: минимальное время запуска, сумму количества тестов и длительностей test suites.
- Ошибка любого файла содержит его путь и причину; частичная выгрузка не выполняется.
- Добавлены регрессионные тесты и пример `examples/magic.tms.json` для отдельных запусков client-unit, client-BFF и server-BFF.
